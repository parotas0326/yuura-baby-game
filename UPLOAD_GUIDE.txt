ゆうら育成ゲーム GitHub Pages アップロード手順
2026-10-15

【最初に】
このZIPにはベビ期・成長期5ゲームと本手順・確認レポートが入っています。
大人24職への進化・カード表示・にっき・図鑑を実装しています。天使・悪魔の正式条件も実装済みです。通常28種コンプ後、天才ルート30点で天使、悪ガキルート30点で悪魔を別々に獲得できます。
ZIPをGitHubへ置くだけでは遊べません。必ずPCで解凍して中身をアップロードします。
全75ファイル（手順・レポート・ライセンスも含む）。分割不要です。
公開先の指定・GitHubへの接続がないため、この納品時点では公開URLは発行していません。

【1 解凍】
Windows：ZIPを右クリック→「すべて展開」。Mac：ZIPをダブルクリック。
展開先を開き、index.html、style.css、ulife.js、script.js、growth.css、growth.js、growth-assets.js、adult-evolution.js、assetsフォルダが見える階層に進みます。
assetsの中身は移動・改名しないでください。画像はPNGとWebPです。形式も変更しないでください。
元の完成版ZIPはバックアップとして保管してください。

【2 リポジトリを作成】
PCのブラウザでGitHubへログイン→右上「＋」→「New repository」。
Repository name に yuura-game などの名前を入力します。
GitHub Freeで公開する場合はPublicを選択します。公開された素材・ソースは他の人も閲覧できます。
Add READMEをONにして「Create repository」を押します。
既存リポジトリを使う場合は先に Code → Download ZIP でバックアップしてください。
既存の無関係なファイルを削除しないでください。本一式と競合するindex.html等は更新対象です。

【3 展開したファイルをアップロード】
リポジトリのCode画面で「Add file」→「Upload files」。
展開したフォルダそのものではなく、その中の index.html、style.css、ulife.js、script.js、growth.css、growth.js、growth-assets.js、adult-evolution.js、assets、
FONT-LICENSE.txt、UPLOAD_GUIDE.txt、TEST_REPORT.txt をまとめてドラッグします。
assetsはフォルダごとドラッグして階層を保ちます。フォルダ内の画像を直下にばらまかないでください。
.nojekyllが見える場合は一緒にアップロードしてください（空の設定ファイルです）。
GitHubは1回100ファイル、ブラウザ経由1ファイル25MiBまで。本一式はいずれも範囲内です。
アップロード完了を待ち、Commit messageに「Publish Yuura game」と入力。
新規リポジトリならmainへCommit changes。保護ブランチの場合は新しいブランチにアップロードし、
Pull requestを作成してmainにマージします。
Code画面直下にindex.htmlがあること、assets/ui/icon-heart.png等が存在することを確認します。
「YUURA_GAME_GITHUB_READY/index.html」のように一段深く置かないでください。

.nojekyllが見えなかった場合：GitHubの「Add file」→「Create new file」で名前を .nojekyll とし、
本文に static site と入力してmainへ保存しても同じように機能します。
本ゲームにはビルド処理・npm・Git LFSは不要です。

【4 Pagesを有効にする】
リポジトリの「Settings」→左の「Pages」。
Build and deployment の Source を「Deploy from a branch」にします。
Branchは「main」、フォルダは「/(root)」を選び「Save」。
しばらく待ち、Pages画面の「Visit site」を開きます。公開に最大10分程度かかる場合があります。
URLの例：https://あなたのユーザー名.github.io/yuura-game/
これは例です。実際のURLはPages画面に表示されたものを使ってください。
github.comのCode画面やZIPのURLはゲームの公開URLではありません。

【5 iPhone Safariで確認】
1. PagesのURLをSafariで開きます。LINE等のアプリ内ブラウザからはSafariに切り替えます。
2. 縦向きでTOP全体、3ボタン、髪・リボン・足が見えることを確認します。
3. Safariの上下バーを表示した状態と隠れた状態で、横縦の不要なスクロールがないか確認します。
4. ♪ OFFをタップしてONへ。音量を上げ、ゲーム操作で音・水音を確認。OFFで止まることも確認します。
5. ミルクを開始。哺乳瓶を指で蛇口の下に運び、水の中で上下左右に振ります。
   水の外・静止では冷えず、積極的な操作約6〜8秒で38℃前後になることを確認します。
   指を離す・画面を切り替える・再び触る操作でドラッグが固着しないかも確認します。
6. いないいないばあは開始前のお手本（いないいない…→バア！）を確認。最初の長押しで10秒が始まり、合図で指を離します。待機で放置しても最初の判定を失わないことを確認。寝かしつけはお手本後の連続タップです。
7. 各ゲーム2回、合計6回を終え、結果から約1.8秒後に自動進化することを確認します。
8. にっき・せっていを開閉し、点数と回数を確認します。
9. URL末尾に ?dev=1 を付けた時だけDEVが出ることを確認します。
10. PCでも同じURLを開き、マウスでドラッグ・押す/離す・クリックを確認します。

【今回の成長期版】
ベビ期6回の進化後、成長期TOPへ進みます。5ゲームを自由に15回プレイできます。
結果と音設定を自動保存します。再読込・Safariを閉じる前の確定結果から再開できます。
ゲーム途中のタイマーは保存せず、途中だったゲームは回数を消費せずやり直します。
プライベートブラウズやブラウザデータ消去では保存が失われる場合があります。
DEVは ?dev=1 のURLのみ。通常プレイとは独立した保存です。
重要：15回後、結果1.8秒→成長演出→対応する大人カードを表示します。
最高能力が同点なら、その候補能力の中で最後に遊んだゲームを優先します。複合・裏進化が先です。
15回分の記録と進化結果は保存されます。全30種の図鑑と秘密2種の条件はTEST_REPORT.txtを確認してください。
更新時は今回ZIPの全ファイルを同じコミットでアップロードしてください。
JS/CSS/素材の一部だけを更新すると版が混在するため避けてください。

【成長期の実機確認】
・ベビ期から各ルートへ進み、5つのボタン・合計点・プレイ回数が見えること（個別能力はにっきで確認）。
・各ゲームで「説明→スタート→3/2/1/START→ゲーム」の順に進むこと。
・お弁当と返却の指ドラッグで画面が動かないこと。
・シャッターは毎回お題を確認してから開始し、正解が2〜8番目に1回だけ出ること。
・縄が頭上→前→足元→背後を回り、足元が光る時にジャンプできること。20回続くこと。
・ドリルは全体15秒、お弁当の見本は3秒で配置に移ること。
・ゲーム終了後に回数/点数が1回分だけ増え、再読み込み後も維持されること。
・15回目の結果から約1.8秒後に成長演出へ進むこと。
・演出途中で再読み込みしても記録が残り、演出を経て進化先が保存されること。
・図鑑とにっきに進化先が記録され、再読み込みで重複しないこと。
・同点では、同点候補の中で直近に遊んだ能力の職へ進むこと。
・「？」で説明を開くとゲームが止まり、閉じると続きを遊べること。
・音ON/OFF、上下バー表示/非表示、ホームインジケータとの重なりを確認すること。
・大人カードの名前・枠が供給素材と同じ表示になり、にっき→図鑑→拡大が開けること。

【困ったとき】
404：Pagesのmain / (root)、直下index.html、Actionsの公開処理成功、公開URLを確認。
画像が出ない：assetsを階層ごとアップロードしたか、大文字小文字・ファイル名を確認。
旧画面が残る：Actions完了後にSafariを再読み込み。必要ならプライベートタブで比較。
初回読込が遅い：LIGHT版の軽量フォント・WebP画像を維持しています。Wi-Fiでも確認してください。
音が出ない：まず♪ONを指でタップしてからプレイ。端末の音量・音声出力先を確認。
古いSafari：最新iOSに更新して再確認。この版はdvh・dialog・Pointer Events等の標準機能を使用します。
