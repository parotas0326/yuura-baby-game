ゆうら育成ゲーム — ベビ期 実装版
================================

■ 開き方
ZIPを「すべて展開」し、YUURA_BABY_GAME内のindex.htmlをChrome / Edgeなどで開いてください。
ZIPの中から直接index.htmlを開くと、画像やCSSを読み込めません。
インストール・ビルド・インターネット接続・外部ライブラリは不要です。
スマホではフォルダ一式を静的Webサーバーへ置き、そのURLを開いてください。
iPhoneの「ファイル」アプリのHTMLプレビューでは動作しない場合があります。

■ 遊び方
好きな順番で3ゲームを各2回、合計6回遊びます。
PERFECT +2点 / CLEAR +1点 / MISS +0点。最大12点。
6回遊んだらホームの「ゆうらが成長するよ！」を押してください。
10〜12点：天才ゆうら / 6〜9点：ガキゆうら / 0〜5点：悪ガキゆうら。
ベビ期の進化までで完成です。進化後の育成は今回の範囲外です。
音は初期OFF。右上の♪ボタンでONにできます。
タブを切り替えた間とDEVを開いた間は、ゲームタイマーが一時停止します。

■ 作成ファイル
index.html：ホーム・DEVダイアログを含む起動ページ
style.css：画面・演出・レスポンシブ・操作領域のタッチ制御
script.js：全ゲーム・タイミング判定・集計・進化・DEV・簡易効果音
assets/crops/：ベビ表情12種、哺乳瓶、手、Zzz、進化先3種の切り出し素材
assets/内のその他：提供ZIPの元素材を変更せず保管
README.txt：この説明書
TEST_REPORT.txt：確認結果とテスト環境

■ 現在の判定値（script.js冒頭で変更可能）
MILK_CONFIG
  startTemp:70、duration:10秒、coolingRate:0.022
  移動距離を流水領域幅320px相当に正規化し、1pxにつき0.022℃冷却。
  押したまま止まっている場合、温度は下がりません。
  流水領域外へ動かした部分、端で止まったままの部分は冷却しません。
  最低15℃。
  表示温度=Math.round(内部温度)。38℃ PERFECT。
  36〜40℃（38℃以外）CLEAR。その他MISS。

PEEKABOO_CONFIG
  duration:10秒、rounds:10回。1秒に1回まで採点。
  良：誤差±120ms以内=3点。可：±300ms以内=1点。その他=0点。
  各秒の開始から470〜700msの間で、最高タイミングを毎回ランダム化。
  顔とゲージで接近を表示。押す→離す操作で判定。
  押さない・離さない・pointercancelの場合、未判定の回は0点。
  20点以上PERFECT / 9点以上CLEAR / 8点以下MISS。

SLEEP_CONFIG
  GOOD：誤差±120ms以内。OK：±250ms以内。
  3・4・5打の3セット。各セットは3候補からランダム選択。
  「どうぞ！」の300ms後が最初のタップ。お手本と同じ時間間隔で入力。
  入力は最も近い未判定音へ割当。1タップで複数音を採点しません。
  成功セット：予定音の75%以上（切上げ）がGOOD/OK、余分なタップ0。
  3セット成功＋全12音の80%以上がGOOD：PERFECT。
  2セット以上成功：CLEAR。それ未満MISS。
  全所要時間はパターンにより約10〜11秒。お手本中はタップ不可。

BABY_EVOLUTION
  geniusMin:10 / kidMin:6
POINTS
  PERFECT:2 / CLEAR:1 / MISS:0

■ DEV
右上DEVで現在の得点・回数・最新結果が見られます。
強制PERFECT/CLEAR/MISSはプレイ中のゲームをその結果で終了。
プレイしていない場合は未完了のゲームを順番に1回分進めます。
「現在の得点で即進化」：未完了でも進化画面をプレビュー。
「指定点数で進化」：0〜12点を入力し、各進化先を確認。
どちらのプレビューも本編の得点を書き換えません。
「ベビ期をリセット」：確認後、全記録を消去。

■ プレイテストで確認してほしいポイント
1. ミルクが38℃に近づく速度。スマホとPCで冷ましやすいか。
2. いないいないばあの1秒ペースと、顔・ゲージの合図の分かりやすさ。
3. 寝かしつけの300ms後の最初のタップと、3→4→5打の難易度。
4. 10点以上の天才ルートが簡単すぎないか、難しすぎないか。
5. 実機スマホでドラッグ・長押し解除・トントンが気持ちよく操作できるか。

■ 既知の制限
保存機能は仕様どおり未搭載。再読み込み・終了で進行状況は消えます。
音はWeb Audio APIの簡易効果音です。ボイス素材はありません。
進化画像は提供された参照シートのメイン部分を四角く切り出した簡易表示です。
元表情シートは隣の絵が近いため、一部の切り出しに細かな端の残りがあります。
ゲームバランスは暫定。人による実機プレイの感触を見て調整してください。
